# PR-002: закрытие требований 4, 7 и 8 ЛР1

## Задача

Закрыть недостающие части ЛР1:

- добавить пользовательский веб-интерфейс поверх существующего HTTP API;
- документировать схему данных и порядок подключения удалённого Git-репозитория;
- сделать Git-процесс воспроизводимым: задача → feature-ветка → осмысленные коммиты → проверки → PR/MR → merge.

## Ветка

`feature/lab-requirements-4-7-8`

## План изменений

1. Добавить страницу `/` и статические JS/CSS-файлы.
2. Подключить веб-интерфейс к `/api/*` и `/health`.
3. Добавить Mermaid-схему данных в `docs/DATA_MODEL.md`.
4. Дополнить README инструкциями по API, схеме и remote.
5. Добавить CI-проверку `make verify` для Pull Request/Merge Request.
6. Провести ревью изменений и выполнить merge в `main`.

## Критерии приёмки

- [ ] `GET /` открывает пользовательский интерфейс.
- [ ] Из UI можно создать катер, команду, сорт рыбы и рейс.
- [ ] Из UI можно добавить улов.
- [ ] Ошибка превышения грузоподъёмности отображается пользователю.
- [ ] `/docs` остаётся доступным как документация API.
- [ ] `docs/DATA_MODEL.md` содержит схему связанных сущностей.
- [ ] `.env` отсутствует среди отслеживаемых файлов.
- [ ] `make quality` и `make test` проходят в окружении с установленными зависимостями.
- [ ] PR/MR содержит результаты проверок и ревью.
