# TASK-008: Отчёт по улову за период

## Цель
Добавить к HTTP API отчёт по суммарному улову рыбы за заданный период рейсов.

## Формулировка задачи
Как сотрудник рыболовной фирмы, я хочу получить сводку по улову за период, чтобы использовать данные для оперативного отчёта без выгрузки всех рейсов вручную.

## Acceptance Criteria
- [ ] Доступен `GET /api/reports/catch-by-period`.
- [ ] Параметры `date_from` и `date_to` необязательны.
- [ ] При указании обеих дат `date_to` не может быть раньше `date_from`.
- [ ] В отчёт попадают рейсы, дата выхода которых входит в диапазон.
- [ ] Для каждого рейса возвращаются `trip_id`, `boat`, `departure_date`, `total_weight_kg`.
- [ ] Результат для рейса без улова содержит `0` кг.
- [ ] Некорректный диапазон дат возвращает HTTP 422.
- [ ] `make verify` проходит без ошибок.

## Definition of Done
Код, тесты, описание API и проверка `make verify` выполнены; изменения готовы к ревью через feature-ветку и PR/MR.
